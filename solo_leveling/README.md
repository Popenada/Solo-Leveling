# Solo Leveling Workout App

A full-stack mobile workout tracking application built with Expo, React Native, NativeWind, and Supabase.

The app allows users to create an account, choose a workout plan, and track fitness progress within a clean mobile interface inspired by the Solo Leveling theme.

---

## Features

- User authentication using Supabase Auth  
- User profiles stored in a Postgres database  
- Required workout plan selection before dashboard access  
- Mobile-first UI built with React Native and NativeWind  
- Navigation handled with Expo Router  
- Secure environment variable management using `.env`  

---

## Tech Stack

### Frontend

- Supabase Postgres Database
